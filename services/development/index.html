How we work

Five stages. Clean handover.

  1. 01

    Specify

    A tight build spec — what the site has to do, the tech stack, the integrations, the hosting, the CMS, the deploy pipeline. Agreed before anyone writes code.

  2. 02

    Scaffold

    Repository, CI, staging environment, CMS. The scaffolding goes up first so every page built from here on is deploying automatically and reviewable by you.

  3. 03

    Build

    Pages, components, templates — built against the design system and tested on real devices. Performance and accessibility audits at each sprint, not at the end.

  4. 04

    Launch

    DNS cutover, redirects configured, analytics live, sitemap submitted, monitoring on. A controlled go-live — not a prayer.

  5. 05

    Support

    Optional retainer for ongoing development, or a clean handover to your in-house team. Documentation written assuming the reader was not in the room.

Frequently asked

Web development questions we hear a lot.

What tech stack do you build websites on?
We default to static-first builds using Astro, with Tailwind CSS for styling, MDX for content collections, and a headless CMS (Sanity, Contentful, or Storyblok depending on fit) when the client needs to edit. For applications we reach for React, Next.js, or Vue where the complexity justifies it — but we start with the lightest architecture that solves the problem.
How much does a custom website build cost?
Custom web development at OakFox typically ranges from £2,500 for a static marketing site to £20,000+ for a multi-section CMS-driven site with integrations. Every quote is case-by-case. We send a detailed written proposal after a free initial call.
What is "green web hosting" and why does it matter?
Green web hosting runs on verified renewable-powered infrastructure — solar, wind, hydro — rather than fossil-fuel-backed grid power. Websites are responsible for a meaningful share of global digital emissions, so hosting choice is one of the highest-leverage sustainability decisions a business makes. We deploy by default to providers on The Green Web Foundation verified list.
Do you work with Shopify, WordPress, or other CMS platforms?
Yes — where they fit. Shopify for e-commerce when the feature set matches; Shopify Hydrogen where a custom frontend is justified. WordPress only when the client has an existing ecosystem we should not break. For most marketing sites we prefer headless CMS options — faster, more secure, easier to maintain, far fewer plugin conflicts.
Will my website be fast and pass Core Web Vitals?
Yes. Every site we build targets a 95+ Lighthouse performance score and green Core Web Vitals out of the box. Static rendering, optimised images, minimal JavaScript, and edge hosting combine to give pages that load in well under a second on 4G. We audit at every sprint, not at the end.
Do you offer ongoing website support and maintenance?
Yes. After launch we offer monthly retainers covering security updates, content edits, performance monitoring, and small feature work. Retainers are scoped to the hours you actually need rather than a fixed package. Alternatively we do a clean handover to your in-house team with documentation written assuming the reader was not in the room.
